# Qurilma va foydalanuvchi qabul sinovi

Har qatorda qurilma/brauzer versiyasi, sana, sinovchi va dalil yozilsin. Emulyatsiya haqiqiy iPhone yoki Android sinovi deb belgilanmaydi.

- [ ] iPhone / Safari: login, klaviatura, modal, pastki menyu, galereya va fayl tanlash.
- [ ] Android / Chrome: shu yo‘llar va ilovadan qaytish.
- [ ] Sayt yopiq paytda Web Push: rozilik, yuborish, bildirishnomani bosish, logout va o‘chirish. iOS cheklovlari ham qayd etilsin.
- [ ] Sekin tarmoqda qidiruv; so‘rov tartibi almashganda eski natija yangisini bosmasin.
- [ ] Chat yuborishda internetni uzish; qoralama saqlansin va retry bitta xabar yaratsin.
- [ ] Fayl yuklash uzilishi; foydalanuvchiga aniq xato ko‘rinsin, saqlanmagan fayl muvaffaqiyatli deb ko‘rsatilmasin.
- [ ] Ikki tabda hisob va paket saqlash; ma’lumotlar yo‘qolmasin.
- [ ] Sessiya tugashi; qayta kirishdan keyin xavfsiz qaytish.
- [ ] Klaviatura: modal ichidagi fokus, Escape, fokusni qaytarish, menyu va galereya.
- [ ] Ekran o‘quvchi; 200% kattalashtirish; uzun ruscha/o‘zbekcha matn.

## 5–10 foydalanuvchi bilan kuzatuv

Har ishtirokchiga yordam bermasdan quyidagilarni bajartiring: o‘yin tanlash; kerakli mahsulotni topish; hudud va yetkazish shartini aytib berish; ikkita mahsulotni solishtirish; sotuvchiga savol yozish; yordam murojaati topish. Vaqt, to‘xtagan joy va xatoni yozing. O‘tkazilmagan suhbat uchun natija yoki statistika to‘qilmaydi.

## Tashqi dalillar

- [ ] Monitoring xati haqiqiy Inbox/Spam papkasida ko‘rildi; provider “accepted” alohida qayd qilindi.
- [ ] Eng yangi sxema bilan backup/restore workflow muvaffaqiyatli tugadi.
- [ ] Qayta tiklangan muhitda ilova ochildi va yopiq media havolalari/kalitlar tekshirildi.
- [ ] Productiondagi muhim hisoblarda 2FA holati tekshirildi; hech kimning 2FA kodi yoki tiklash kaliti hisobotga kiritilmadi.
